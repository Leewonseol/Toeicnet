# 학습용 어휘 표

**[vocabulary.csv](vocabulary.csv)** 하나에 해커스 토익 보카 DAY 01–30의 표제어 5,078개가 있다(본 단어 1,241 · 기초 837 · 800점 2,040 · 900점 962, Anki 덱과 뒷단어 PDF 기준). Excel에서 바로 열 수 있다(UTF-8 BOM). 파일이 커서 GitHub 화면에서는 표로 보이지 않는다. 검색·필터·복습은 아래 [학습 페이지](#학습-페이지-studyhtml)에서 한다.

| 열 | 내용 |
| --- | --- |
| DAY, 구분 | 교재 DAY와 덱(본 단어·기초·800점·900점). 두 DAY에 나오는 표제어는 함께 적었다 |
| 표제어, 품사 | 품사는 PDF 표지 판독값 또는 사전·뜻풀이 추정값이다(오류가 있을 수 있음) |
| 뜻 | 교재 원뜻. 한국어 뜻이 따로 검증되지 않은 항목은 사전으로 확인한 `영어 정의:`를 함께 적었다 |
| 파생어 | 같은 단어에서 접사로 만들어진 교재 어휘와 그 뜻 |
| 합성어 | 이 단어가 들어간 합성어(또는 이 합성어의 구성어)와 그 뜻 |
| 접두사, 접미사 | 접사의 뜻·기능과 분해 형태 |
| 어근 | 이 단어가 유래한 원형 단어와 그 뜻(Wiktionary 기록) |
| 공통 어원 | 역사적으로 같은 어근에서 온 교재 어휘와 그 뜻(현대 파생 관계와 구별) |
| 동의어 | 같은 의미의 단어와 그 의미의 정의 |
| 유의어 | 비슷한 뜻의 교재 어휘와 그 교재 뜻 |
| 사용 용법 | 이 단어가 들어간 교재 표현과 그 뜻, 문법 주의(타동사·불가산명사 등) |

모든 관련어·표현은 `단어 — 뜻` 형식이며 셀 안에서 줄바꿈으로 구분한다. 관계가 없거나 뜻의 근거가 없는 칸은 비워 두었다. 그 구분과 검증 기록은 `internal/`(분석용 표, 검토 대기열)에 있다.

`뜻`의 교재 원뜻은 해커스 저작물로, 비공개 저장소에 개인 학습용으로 둔 것이다(재배포 금지). 영어 정의·동의어·어근 뜻풀이의 출처 표시는 [SOURCES.md](../SOURCES.md)와 [LICENSES.md](../LICENSES.md)에 있다.

## 학습 페이지 (study.html)

[study.html](study.html)은 이 폴더의 `vocabulary.csv`를 그대로 읽는 단일 HTML 파일이다. CSV를 나누거나 다른 형식으로 바꾸지 않으므로 `build_vocabulary_csv.py`로 CSV를 다시 만들면 페이지도 새 내용을 쓴다. 페이지에는 어휘 데이터와 인증 정보가 들어 있지 않다(`tests/test_study_html.py`가 확인).

| 기능 | 내용 |
| --- | --- |
| 검색 | 영어 표제어(악센트 무시: resume → résumé)·한국어 뜻·관련어 전체 또는 파생어·합성어·접두사·접미사·어근·공통 어원·동의어·유의어·사용 용법 열 하나. 여러 단어는 모두 포함한 행만 |
| 필터 | DAY, 본 단어·뒷단어(전체·기초·800점·900점), 품사, 학습 상태(미학습·학습함·복습 예정·'다시' 2회 이상) |
| 목록 | 한 쪽에 30개만 그린다. 행을 누르면 상세(뜻·관련어·학습 상태)를 펼치고 접는다. 관련어를 누르면 그 단어로 검색한다 |
| 인출 학습 | 영어 → 뜻(답을 떠올리거나 적은 뒤 확인), 뜻 → 영어(입력한 표기를 비교, 뜻풀이 속 표제어는 가림), 섞기. 첫 글자 힌트 |
| 간격 반복 | 다시·어려움·알맞음·쉬움 자기 평가로 다음 복습일을 정한다(SM-2 변형). '다시'는 같은 학습 안에서 다시 나온다. 하루 새 단어 수를 정한다. 범위는 현재 찾아보기 결과 또는 전체 |
| 학습 이력 | 단어별 상태와 평가 기록을 브라우저 IndexedDB에 저장한다. JSON으로 내보내고, 다른 기기에서 가져와 합친다. DAY별 진행과 최근 14일 평가 수를 보여 준다 |

학습 기록은 표제어(대소문자 무시)를 키로 쓴다. CSV를 다시 만들어 표제어 표기가 바뀌면 그 단어는 새 단어로 보이고, 이전 기록은 지우지 않고 보존한다.

### 여는 방법

**iPhone·iPad (GitHub Pages).** `main`에 반영된 뒤 저장소 Settings › Pages › Source를 **GitHub Actions**로 정하면 `.github/workflows/study-page.yml`이 `study.html` 한 파일만 `https://leewonseol.github.io/Toeicnet/`에 게시한다. 이 주소는 공개이지만 데이터가 없는 빈 페이지다. 처음 열면 CSV를 고르는 화면이 나온다.

1. GitHub에 로그인한 Safari에서 `vocabulary/vocabulary.csv`를 열고, 다운로드 버튼을 누르거나 Raw를 길게 눌러 '링크된 파일 다운로드'를 고른다(파일 앱 › 다운로드).
2. 학습 페이지에서 'CSV 파일 선택'으로 그 파일을 고른다. CSV는 이 기기의 브라우저 저장소에만 보관되고 서버로 보내지 않는다(페이지의 CSP가 다른 출처로의 연결을 막는다).
3. CSV가 바뀌면 기록 탭의 '다른 CSV 불러오기'로 다시 고른다.

비공개 저장소의 Pages는 유료 플랜에서만 켤 수 있다. 켤 수 없으면 아래 방법을 쓴다.

**컴퓨터 또는 Codespaces.** 저장소 루트에서 아래 명령을 실행하고 `http://localhost:8000/study.html`을 연다. 같은 폴더의 `vocabulary.csv`를 자동으로 읽는다. Codespaces에서는 포워딩된 8000번 포트 주소(기본 비공개, GitHub 로그인 필요)를 iPhone Safari에서도 열 수 있다.

```sh
python -m http.server 8000 --directory vocabulary
```

### iOS Safari에서 기록 보관

- Safari는 7일 동안 방문하지 않은 사이트의 저장소를 지울 수 있다. 공유 › '홈 화면에 추가'로 연 앱은 이 제한을 받지 않지만, Safari 탭과 저장소가 따로라서 CSV와 기록을 한 번 더 불러와야 한다.
- 마지막 내보내기 후 7일이 지나면 상단에 안내가 나온다. 기록 탭의 '기록 내보내기'로 JSON을 파일 앱에 보관하고, 다른 기기나 새 저장소에서는 '기록 가져오기·합치기'로 합친다(단어별로 마지막 평가가 늦은 쪽, 평가 기록은 합집합).
- 개인 정보 보호 브라우징에서는 저장소를 쓸 수 없을 수 있다. 이때는 기록 탭에 표시되고 탭을 닫으면 기록이 사라진다.
