# 한국어 뜻 검증

한국어 원뜻은 원천 출현에 보존한다. 별도 검토에서 해당 의미와 맞는 한국어 뜻을 확인한 경우에만 검증 뜻으로 기록한다. 검토 근거는 영한사전, 한국어 실제 용례 또는 명시적 영한 의미 대응 기록을 사용한다. 문맥 의존과 부분 대응은 별도 상태로 유지한다. [검토 형식](../analysis/README.md)

등록 건수는 [SQLite 측정 결과](database.generated.md)에서, 원뜻·검증 뜻·근거와 사유는 [한국어 뜻 CSV](../data/processed/korean_translations.csv)에서 확인한다.
